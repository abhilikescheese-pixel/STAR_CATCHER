# STAR_CATCHER⭐ƪ(˘⌣˘)ʃ
Star catcher is a simple arcade game that is made in python and pygame 

You have to move your basket using your keyboards right and left arrow key ,making sure to collect as much falling stars for points. When a star touchs the ground the game ends.

-Main features-
Main menu
score counter
level system
increased difficulty the more points you get
game over screen
restart option (by pressing R)

-How to play-
left arrow - move left
right arrow - move right
SPACE - start the game
R - restart the game (on Game over screen)

-Level system-
Every 10 points collected the star fall to the ground faster, making the game challenging

-Built with-
Vs code (Python)
Pygame
